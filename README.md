# computer_soul
Simple cpu memory weather monitor for Linux Mint 22.2
Please see the picture: ScreenShot.png
Put the file: soul_gui.py into HOME folder
Right mouse button on file and choose Options/Permissions and check all EXECUTION boxes 
Now move the file: Душата.desktop on the Desktop and do the same:  Right mouse button on file and choose Options/Permissions and check all EXECUTION boxes
That's it - now you can use the program.
